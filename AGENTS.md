# nothing-first

This repository ships one agent skill. Its canonical text is [skills/nothing-first/SKILL.md](skills/nothing-first/SKILL.md) — read it and follow it for any development or design task; when working with SQL/Postgres, also read [skills/nothing-first/references/sql-postgres.md](skills/nothing-first/references/sql-postgres.md).

Core principle: **the ultimate optimization of any entity is its absence — the best code is the code that does not exist.** Start every proposed entity at rung 0 of the Existence Ladder (Nothing > Exists > Structure > Declaration > Derivation > Reaction > Orchestration) and fall one rung only when the current rung provably cannot meet the need.

Claude Code users: install via the plugin marketplace or symlink `skills/nothing-first` into `~/.claude/skills/` (see [README](README.md)). Agents on other platforms: load SKILL.md as standing instructions.
