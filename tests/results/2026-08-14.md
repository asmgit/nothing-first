# Results — 2026-08-14

Skill text under test: commit `2529ce9` (the defence rules — Defence test, a defence spoken before the thing exists, a failed defence as a redesign order). Two new scenarios, both arms each, four independent judges with executed code gates. Single run per arm (n=1), stated explicitly.

## Split verdict — 1 win, 1 loss

| Scenario | Baseline | With skill |
|---|---|---|
| `defence-priced-choice` (temptation) | FAIL axes 1–2 | PASS 5/5 |
| `defence-underbuild` (over-application) | PASS 3/3 + gate | NOT COMPLIED, axis 4 |

**`defence-priced-choice`.** The baseline design is the right structure — deny-by-default classification, swap-on-success — and its textual-column guarantee executes correctly. It still fails the hard requirement, proven by fixture rather than argued: bigint columns named `msisdn`, `tel`, `cell` produce zero errors from its own coverage gate, so the name denylist the answer explicitly condemns returns in its non-textual branch; and the gate checks one schema while `pg_restore` restores all of them. Its only alternative (PostgreSQL Anonymizer) is named in the closing paragraph and left unpriced as the reader's choice — mention-both, not a defence. The with-skill run refuses the rewrite, hands enforcement to `anon.privacy_by_default`, and prices the rejected option in one sentence: an afternoon's work, and the column list stays hand-maintained, so the requirement stays unmet. Ownership 9 → 4 entities, 163 → 10 LOC, 21 → 0 logic ops.

**`defence-underbuild`.** The scenario was written to catch the failure a minimalism skill is most likely to cause, and it caught it — in the opposite place from the one expected. Neither arm underbuilt the money logic: both anchored totals to the ledger instead of recomputing, both handled per-currency minor units. The with-skill arm failed on delivery: prose where the prompt said "ship today", justified by a reason that only covers writing into the wrong repository, while the arm preamble authorized a generic answer and the baseline shipped a runnable three-file generator under the same missing facts — labeling them as assumptions behind a fail-closed check. Its zero LOC is the failure, not a minimalism win, so the pair prints no complexity delta.

## What the judges found in the skill text

Both judges, independently, named the same escape hatch first: *"materialize what the accepted design keeps, **or say why not**"* — any stated reason converted non-delivery into apparent compliance, because the text never required the reason to cover the gap. Three more, one per judge: *"an unreachable scope is named and skipped, not stalled on"* parked an environment question that RDS makes fatal; *"confirming the load-bearing ones"* let naming an assumption pose as confirming it, next to a `random_phone()` signature written from memory under a Sources list; and the Defence test's *"price both"* set no precision floor, so "an afternoon's work" against an unpriced chosen side satisfied the letter.

## Patched in response

- The delivery clause now has to cover the whole gap: an unreachable target is no licence to ship nothing while a generic version, a scratch copy, or the same design with labeled assumptions was buildable, and missing facts argue for labeled assumptions behind a loud check rather than for withholding the artifact.
- Naming a question is not answering it, and for wider-world claims the look is the current source read now, never a citation appended to something written from memory.
- The chosen side is priced like the refused one — a size is not a cost, and costs stated for the rejected option alone make an argument, not a defence.
- The deletion pass is asked as a stranger would ask it, and a pass ending "nothing to simplify" names the simpler shape it weighed. A new Simplicity judge in the harness does the same from outside: it does not score the answer, it tries to beat it.

## Honest fine print

Single run per arm, so the split is two data points, not a rate. The two scenarios were authored by the same session that wrote the rules they test — a judge could not have been fooled about what the runs did, but scenario choice is not independent of the author. The with-skill loss is the more useful of the two results: the win confirms what six earlier scenarios already showed, while the loss found a defect in the text that no amount of re-reading had surfaced.
